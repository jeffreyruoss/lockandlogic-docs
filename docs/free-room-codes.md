# 🎫 Free Room Codes

> How to give someone a free room — a contractor, a charity donation, a giveaway winner, or a guest you want to make things right with.

---

## How it works

You have **five standing offers** set up in Bookeo. Four are locked to a single room each, and one works for any room. Each one holds a list of codes, and **every code works exactly once** — the moment someone books with it, that code is dead.

| Offer | What it's good for |
|-------|-------------------|
| Comp - Grandma Betty's Secret Recipe | That room only |
| Comp - The Forgotten God | That room only |
| Comp - The Initiation | That room only |
| Comp - Nikola Tesla's Workshop | That room only |
| Comp - Any Room | Guest picks whichever room they like |

Three codes are loaded into each one, ready to hand out. When you run low, you can add more (see below).

**The whole room is free, no matter how many people come.** A code takes 100% off the booking, so whether it's two people or eight, the total is $0. This was tested with a full room of eight — $280 down to $0.

---

## Which one should you use?

**"Comp - Any Room"** is the one you'll reach for most. It covers the everyday cases: a raffle prize, a donation to a local fundraiser, an apology to a guest whose game didn't go well. They pick the room they want.

**The four room-specific offers** exist for when someone should play *each* room once. That was the original reason we built this — your contractor gets one code per room, so he can play all four but can't accidentally use all his codes on the same one.

---

## Reading the codes

Every code looks like this: **`RG-7K2X`**

The first two letters tell you which room it's for:

- **RG** — Grandma Betty's Secret Recipe
- **RF** — The Forgotten God
- **RI** — The Initiation
- **RT** — Nikola Tesla's Workshop
- **RA** — Any room

The four characters after the dash are random, which keeps the codes from being guessable. That matters more than it sounds — a free room is worth up to $280, and you don't want someone typing lucky guesses at checkout.

---

## Handing out a code

1. Open **Marketing → Promotions** in Bookeo and click the offer you want.
2. Click **Manage** to see its list of codes.
3. Pick an unused one (the "Time of use" column will be empty) and give it to the guest.

::: warning The guest has to book it themselves
Codes only work on the **public booking page** — the one customers use. They do **not** work when you're creating a booking from the Bookeo dashboard.

So send the guest the code and let them book their own day and time. If you'd rather book it for them at the front desk, don't use a code at all — create the booking and use **Additional items/adjustments** to take the price down to $0 instead.
:::

---

## Seeing who used what

Everything is tracked automatically. In Bookeo, go to **Marketing → Promotions**, open the offer, and click **Manage**. For each code you'll see:

- **Time of use** — when it was redeemed (blank means it's still available)
- **Booking** — a link straight to the booking, which shows you the guest's name and which room they played

There's also a **Coupons report** under **Marketing → Reports** if you'd rather download the whole lot as a spreadsheet.

You don't need to keep your own list of who got which code. The one thing Bookeo can't tell you is who's holding a code they haven't used yet — so if that matters, jot it down when you hand one out.

---

## Adding more codes

When an offer runs low, open it, click **Manage**, then:

- **New** — type in a single code by hand. Easiest for a one-off.
- **Import** — upload a spreadsheet with one code per row. Better for a batch.

Keep to the same naming pattern (room letters, dash, four random characters) so the codes stay readable at a glance.

::: tip These codes don't expire
Codes stay valid indefinitely until someone uses them. That's a deliberate choice — just be aware that a code written on a card in someone's drawer will still work a year from now. If you ever want a batch to lapse, ask your developer to add an expiry date.
:::

---

## Things worth knowing

**A cancelled booking burns the code.** If a guest books with a comp code and then cancels, the code does not come back — you'll need to give them a new one.

**Codes don't create availability.** A code only changes the price. The guest still books from whatever times are open on the calendar, so if a date is closed or fully booked, a code won't get them in.

**One code per booking.** A guest can't stack two codes on the same game.
