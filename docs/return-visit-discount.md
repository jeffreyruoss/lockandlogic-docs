# Return Visit Discount

Give guests **10% off** when they book their next room before they leave. There are two ways to do it — both work fine, so pick whichever fits the moment.

---

## Option 1: Adjust the Price (Simplest)

Staff book the guest's next visit right at the front desk and take $3 off.

1. Open the Bookeo dashboard and create the booking for the guest.
2. Under **Additional items/adjustments**, enter **-$3**. The total drops from $30 to **$27**.
3. Charge the $27 on the **Square POS** card reader.

Nothing for the guest to type or remember — staff handle it all at the desk.

---

## Option 2: Send a Discount Code

Give the guest a code and let them book their own next visit online.

1. In Bookeo, go to **Marketing > Promotional codes** and create a code. Set **Max total uses** to **1** so it's one-time only — it can't be shared or reused.
2. Email or text the code to the guest so they can copy and paste it.
3. The guest books on the website and enters the code at checkout.

One thing to know: promo codes only work on the **public booking form** on the website, **not** in the staff dashboard. So with this option the guest books themselves — staff can't enter the code on their behalf.

---

## Which Should You Use?

- **Adjusting the price** is quickest and keeps everything at the desk — best for booking on the spot.
- **A code** is handy if the guest isn't ready to commit right then and wants to book later from home.

Either way the discount is the same. Bookeo can't auto-generate codes, so each one is created by hand — which is why, for an on-the-spot rebooking, Option 1 is usually a little less work.

---

## Payment Setup

Bookeo can use two payment processors at the same time:

- **Stripe** — online payments (guests booking on the website).
- **Square POS** — in-person payments (tap or swipe at the front desk).

They run independently, and everything records in Bookeo — one set of booking records, nothing to reconcile.
