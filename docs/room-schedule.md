# Room Schedule

Daily time slot schedule for all four core rooms.

::: warning Provisional — some details pending client confirmation
This is a working draft. **Updated June 28, 2026:** the client confirmed **Monday–Friday opening at 4:30 PM**. The weekend open (noon) and exact closing time are still pending confirmation. The **30-minute reset** between bookings (set June 25, up from 15) applies to the four core rooms; the **holiday room uses a 15-minute reset** since it's a 30-minute game.
:::

- **Game duration:** 60 minutes (core rooms)
- **Reset time:** 30 minutes between sessions (core rooms; up from 15)
- **Per-room cycle:** 90 minutes (60-minute game + 30-minute reset)
- **Stagger:** Each room starts 15 minutes after the previous one
- **Open days:** closed Tuesdays (since November 4, 2026)
- **First game:** 4:30 PM Mon, Wed–Fri · 12:00 PM Sat–Sun
- **Cost:** $35/person (tax included)
- **Players:** 2–8 per room

**A note on closing time:** because the four rooms are staggered 15 minutes apart, the last room (The Forgotten God) starts at 9:45 PM and finishes at **10:45 PM** every day. So while the booking window closes around 10:00 PM, the building stays occupied until roughly 10:45 PM — operating hours need to extend past the final game. The exact close still needs the client's sign-off.
