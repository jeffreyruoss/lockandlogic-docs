# Room Schedule

Daily time slot schedule for all four core rooms.

::: warning Provisional — pending client confirmation
The schedule below is a working draft. **Updated June 25, 2026:** the reset time between bookings was increased from 15 to **30 minutes** at the client's request, to give plenty of time to reset each room. The longer reset lowers the number of sessions that fit in a day, so the slot tables and weekly totals below were recomputed under the assumptions noted. Operating hours and the exact slot times still need final sign-off before they're configured in Bookeo.
:::

- **Game duration:** 60 minutes
- **Reset time:** 30 minutes between sessions (up from 15)
- **Per-room cycle:** 90 minutes (60-minute game + 30-minute reset)
- **Stagger:** Each room starts 15 minutes after the previous one
- **Cost:** $35/person (tax included)
- **Players:** 2–8 per room

**Assumptions used to build the tables:** operating hours unchanged (Mon–Fri 5–10 PM, Sat–Sun 12–10 PM), 30-minute reset after every game, a 15-minute stagger between rooms, and each game ending by close. Adjusting the hours (e.g. opening earlier on weekends) would recover sessions lost to the longer reset.
