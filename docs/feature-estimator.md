# Interactive Feature Estimator

Use this tool to build your custom feature set and see the estimated cost in real time. Check or uncheck features to see how they affect the project total.

**What's included in estimates:** Design, development, testing, and deployment. Content writing (copy, photos, etc.) is not included.

**Booking platform:** The final platform choice hasn't been made yet. Some features have different estimates depending on the platform. Toggle between Bookeo and Resova to compare — both totals are shown at the bottom.
